漢字プリント作成・GitHub公開用

index.html、app.mjs、core.mjs、data-format.mjs、pdf.mjs、readings.mjs、sample-data.mjs、style.css、.nojekyll を同じ場所に置いてください。

追加機能：学年別単元一覧、チェックをすべて外す。
現在の単元データは２年・下10〜12月の７単元・35問です。ほかの学年は未登録です。
学年を切り替えると単元の選択を解除します。編集したプリントは消えません。

ブラウザ保存は同じ端末・同じブラウザ・同じURL内です。別のURLへ移す場合、元の画面で「このプリントを書き出す」を使い、新しい画面でデータを読み込んでください。

GitHub版にはChatGPTの非公開設定は引き継がれません。児童の実名などを公開ファイルへ入れないでください。名前の入力や保存は閲覧端末のブラウザ内です。
